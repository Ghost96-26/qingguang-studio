# 擎光绘影本地管理后台

管理后台用于查看平台账户、访问记录和资源用量，并调整平台级账户权限。它只接受本机直接访问，公网隧道、反向代理和局域网设备均无法打开管理页面或调用管理接口。

## 打开方式

- 双击项目根目录的 `15_Open_Local_Admin_Console.cmd`。
- 或先启动工作台网关，再访问 `http://127.0.0.1:8090/v3/admin`。
- 也可在创作台的“账户与项目设置”中选择“管理后台”。该入口只在本机、且当前账户为平台主管或平台管理员时显示。

管理后台不依赖模型运行服务，因此查看用户和调整权限时无需启动显卡模型。

## 可查看的信息

- 平台总览：启用与暂停账户数、在线会话、有效邀请、项目数、最近 30 天任务量与计算时长、素材存储量。
- 用户与权限：姓名、邮箱、账户状态、平台角色、所属项目、最近 30 天用量、在线会话和最近设备。
- 访问记录：成功登录、失败登录、退出、密码与资料更新、账户权限调整、会话撤销。

这里的“在线会话”表示尚未过期且未撤销的登录凭证，并不等同于用户正停留在页面上；设备最后活动时间最多约五分钟更新一次。

## 可调整的权限与额度

| 设置 | 作用 |
| --- | --- |
| 账户状态 | 暂停后立即撤销该用户全部登录会话、未完成上传和临时下载凭证。 |
| 平台角色 | 普通成员、平台管理员、平台主管；平台管理员可以使用本地管理后台，但不会自动获得其他人的项目内容权限。 |
| 允许创建项目 | 关闭后用户仍可进入已有项目，但不能新建项目。 |
| 月运行额度 | 限制该账户跨全部项目的月计算时长；留空表示不限，0 表示禁止提交新的生成任务。 |
| 同时任务上限 | 限制该账户跨全部项目处于排队或运行状态的任务数。 |
| 下线设备 | 撤销该用户的有效登录会话；对当前管理员执行时会保留当前管理会话。 |

平台级额度和项目级额度会同时生效，任一达到上限都会拒绝新的生成任务。项目成员角色、项目内额度和队列优先级仍由项目负责人在“成员与邀请”页面管理。

## 安全边界

- 页面 `/v3/admin` 和全部 `/v1/admin/*` 管理接口同时检查“本机直连”和“平台管理员”两个条件。
- 代理请求即使携带有效 Cloudflare 边缘密钥和管理员会话，也会被管理接口拒绝。
- 本机平台主管账户不能被暂停或降级，当前管理员不能停用自己或移除自己的管理权限。
- 每次权限调整和会话撤销都会写入审计记录。
- 公网用户仍通过邀请制登录；平台管理员权限不代表项目内容访问权。

## 日常操作建议

1. 在“总览”确认在线会话、有效邀请和当前任务队列是否符合预期。
2. 在“用户与权限”搜索目标账户，展开后核对其项目范围和最近设备。
3. 调整权限或额度并保存；暂停账户前页面会再次确认。
4. 怀疑会话泄露时使用“下线全部设备”，再让用户重新登录。
5. 在“访问记录”核对操作是否生效，并留意重复登录失败事件。

运行数据库、账户信息、会话、模型文件、素材和密钥均属于本地运行数据，不应提交到公开仓库。公开仓库只需保留本说明、脱敏配置示例和安装脚本。
